# ORU 개발자 가이드

브라우저에서 **[http://localhost:3000/developer](http://localhost:3000/developer)** 로 이 문서를 볼 수 있습니다.  
처음 열면 비밀번호를 한 번 입력합니다. 통과하면 `/designer`와 `/developer`를 같이 볼 수 있습니다.

이 폴더는 **주니어 개발자가 ORU 코드베이스를 혼자 탐색할 수 있도록** 만든 내부 문서입니다.  
공식 사이트 설정·기여 규칙은 저장소 루트의 `README.md`, `CONTRIBUTING.md`, `BACKEND_SETUP.md`를 함께 보세요.

| 순서 | 문서 | 한 줄 요약 |
|------|------|------------|
| 1 | [프로젝트 개요 & 기술 스택](./01_overview.md) | ORU가 무엇을 하는지, 왜 이 기술을 쓰는지 |
| 2 | [디렉토리 구조 및 역할](./02_structure.md) | 폴더가 식당의 어느 구역인지 |
| 3 | [핵심 데이터 흐름](./03_data_flow.md) | 클릭부터 화면까지의 여정 |
| 4 | [주요 기능 딥다이브](./04_core_features.md) | 리뷰 · 커뮤니티 · 플레이리스트 |
| 5 | [로컬 실행 가이드](./05_getting_started.md) | `.env`부터 `npm run dev`까지 |
| 6 | [포트폴리오용 프로젝트 소개](./06_portfolio.md) | 이력서·면접에 옮겨 쓰는 문장 |
| 7 | [피드백 & 아이디어](./07_feedback.md) | 사이트를 보며 이러면 좋겠다 |

시각 언어·컬러·타이포는 [/designer](/designer) 를 보세요.
