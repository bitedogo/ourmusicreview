# 07. 피드백 & 아이디어

> 사이트를 보면서 **이러면 좋겠다**는 메모를 날짜별로 쌓습니다.  
> 새 날짜는 이 안내 바로 아래(최신이 위)에 넣습니다.

버그를 고친 기록, 시안을 맞춘 기록, 비밀번호 같은 구현 로그는 적지 않습니다.

각 항목은 화면에서 무엇이 아쉬운지 / 이렇게 하면 좋겠다 / 상태(`대기` 또는 `반영함`) 순입니다.

구현 쪽은 [/developer/07_feedback](/developer/07_feedback) 와 짝입니다.

## 2026-09-20

#### 검색·앨범 목록 리뷰 작성은 같게

검색과 앨범 리뷰 목록의 「리뷰 작성」이 오류일 때 다르게 움직인다. 이미 있으면 중복 안내, 없으면 작성, 비로그인이면 로그인, 그 외 오류면 작성으로 안 가고 이유를 보여 주면 좋겠다. 동작은 [개발자 07](/developer/07_feedback).

상태: **반영함**

#### 대시보드 메인 문구

대시보드 인사가 어색하다. 제목은 「ORU ADMIN DASHBOARD」면 좋겠다. 동작은 [개발자 07](/developer/07_feedback).

상태: **반영함**

#### 관리자 화면은 헤더 없이

대시보드 위 로고·탭 헤더가 겹쳐 보인다. `/admin`은 헤더 없이 카드만 있으면 좋겠다. 동작은 [개발자 07](/developer/07_feedback).

상태: **반영함**

#### 사이트와 대시보드를 오가는 버튼

관리 화면과 공개 사이트를 헤더만으로 오가기 어렵다. 오른쪽 아래에 지금 있는 곳의 반대 버튼만 두면 좋겠다. 사이트에서는 GO DASHBOARD, 대시보드에서는 GO WEBSITE. 색은 ORU 청록. 동작은 [개발자 07](/developer/07_feedback).

상태: **반영함**

#### 관리자는 공개 사이트와 다른 화면

관리 화면이 일반 헤더·메뉴 안에 붙어 있어 운영 콘솔처럼 안 보인다. 공개 헤더·푸터를 빼고, `/admin`은 회색 배경·알약 탭·숫자 카드가 있는 전용 홈이면 좋겠다. 공개 헤더의 「관리자」 메뉴는 없애고, 프로필의 「관리」로만 들어가면 좋겠다. 동작은 [개발자 07](/developer/07_feedback).

상태: **반영함**
