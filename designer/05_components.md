# 05. 컴포넌트 & 핸드오프

> 새 화면을 그릴 때 **이미 있는 부품을 재사용**하는 것이 첫 번째 디자인입니다.  
> 아래는 제품에 반복되는 패턴과, Figma를 개발에 넘길 때 적는 메모입니다.

이 페이지 하단의 실물 샘플을 함께 보세요.

---

## 반복되는 UI 부품

| 부품 | 보이는 곳 | 디자인 포인트 |
|------|-----------|----------------|
| 검색바 | 홈 히어로 | 둥근 트랙 + 오른쪽 청록 버튼 |
| 피처드 카드 | 홈 슬라이드 | 커버 + 제목/아티스트 + Rating |
| 오늘의 앨범 | 홈 | 종이색 탭 + 보더 카드. 고른 탭만 흰색이고 카드와 붙음 |
| 평점 뱃지 | 리뷰 카드 커버 좌하단 | 흰 배경, 점수 컬러 + 회색 `/10` |
| 인터랙션 필 | 리뷰·글 상세 | 좋아요 / 공유 / 신고 — 회색 보더 필 |
| 댓글 | 리뷰·게시글·플리 | 아바타 + 본문, 대댓글은 1단만 |
| 페이지네이션 | 리뷰 목록, 게시판 | 숫자 + 이전/다음 |
| 빈 상태 | 목록이 없을 때 | 점선 보더, 보조 회색, 가운데 정렬 |
| 에디터 | 리뷰·글 작성 | Toast UI, 이미지 최대 ~380px |

## 주요 화면 인벤토리

Figma 페이지를 나눌 때 이 목록과 1:1로 두면 빠짐이 없습니다.

```
홈            / 
검색          /search
리뷰 목록     /reviews
리뷰 작성     /review/write
리뷰 상세     /review/[id]
앨범 리뷰     /review/album/[albumId]
게시판        /boards/domestic|overseas|market|workroom|notice
글 상세/작성  /community/[id]  /community/write
플리 탐색     /playlist  /playlist/[id]
내 프로필     /profile  및 하위
타인 프로필   /users/[userId]
로그인/가입   /auth/signin  /auth/signup
FAQ·약관     /faq  /policies/*
관리자        /admin/*
```

`/profile` = 나, `/users/...` = 다른 사람. 헤더·공개 설정·편집 버튼 유무가 다릅니다. **한 프레임을 복제해 두 용도로 쓰지 말고** “나 / 타인”을 구분해 주세요.

---

## 버튼 위계

1. **Primary** — 브랜드 청록 배경, 흰 글. 한 화면에 하나 (작성, 저장, 가입).
2. **Secondary** — 흰 배경, `#D9D9D9` 보더, `#505050` 글. 좋아요·공유·신고 필.
3. **Text / 링크** — 청록 또는 밑줄. 푸터, “홈으로”.
4. **Danger** — 평점 빨강을 재사용하지 말 것. 삭제 확인은 별도 카피로 충분하고, 큰 빨간 면은 피한다.

호버는 청록을 `#3796A0`으로 한 단계만 어둡게. 스케일 애니메이션은 모달 등장(0.95 → 1, 200ms) 정도만 씁니다.

## 이미지

| 종류 | 처리 |
|------|------|
| 앨범 커버 | iTunes/외부 URL. 슬라이드·일반 카드·오늘의 앨범은 15px. 없으면 “이미지 없음” |
| 프로필 | 원형, R2 WebP, 긴 변 400px로 압축되어 올라옴 |
| 플리 커버 | 커스텀은 업로드(자른 정사각), 자동은 iTunes 아트 |
| OG/로고 | `/oru_logo.png` |

업로드 이미지는 개발 쪽에서 400px WebP로 줄어듭니다. Figma에 4000px 원본 품질을 기대한 목업을 넣으면 실제와 갭이 납니다. **프로필·커버는 작은 정사각이 최종본**입니다.

## 개발자에게 넘기는 체크리스트

시안 옆에 이 네 가지만 적어도 핸드오프가 빨라집니다.

1. **브레이크포인트** — 390 / 640 / 768 중 어느 프레임인지
2. **토큰 이름** — `#43A7B2` 대신 `brand-primary`, 간격은 `72 → 101`처럼 기존 리듬
3. **상태** — default / hover / empty / loading / 비로그인 / 타인 프로필
4. **컴포넌트 재사용** — “리뷰 상세 필과 동일”, “게시판 테이블과 동일”

새 색·새 폰트·새 라운드 값은 “왜 기존 토큰으로 안 되는지” 한 줄을 붙여 주세요.

변수 원본은 `app/globals.css`의 `:root` 입니다. 개발 가이드는 [/developer](/developer) 입니다.
