# 04. 레이아웃 & 간격

> ORU 페이지는 **가운데 1100px 종이** 위에 그려집니다.  
> 종이 바깥은 흰 여백이고, 종이 안쪽 좌우는 모바일 24px / 데스크톱 40px 입니다.

---

## 캔버스

```
|<--------- 브라우저 전체 (흰 배경) -------->|
|      |<---- max 1100px ---->|             |
|  24/40px  콘텐츠 영역   24/40px           |
```

| 토큰 | 값 | 의미 |
|------|-----|------|
| `--layout-content-max-width` | 1100px | 본문 최대 너비 |
| `--page-padding-x-mobile` | 24px | 페이지 좌우 (모바일) |
| `--page-padding-x-desktop` | 40px | 페이지 좌우 (640px+) |
| `--site-padding-x-mobile` | 16px | 더 좁은 크롬(일부 헤더) |

게시판·약관 등 읽기 화면은 `max-w-4xl` / `max-w-3xl` 처럼 **더 좁게** 가기도 합니다. 홈·검색이 1100px 풀 캔버스입니다.

## 반응형 끊기는 지점

Tailwind 기본 브레이크포인트를 씁니다. Figma 프레임을 잡을 때 이 숫자에 맞추면 개발과 어긋나지 않습니다.

| 이름 | 너비 | 이 지점에서 바뀌는 것 |
|------|------|------------------------|
| 기본 | ~375 | 모바일 기준 설계 |
| `sm` | **640px** | 로고 확대, 히어로 36px, 푸터 데스크톱, 페이지 패딩 40px |
| `md` | **768px** | 헤더 가로 메뉴, 히어로 스티키 동작 |

새 컴포넌트를 “모바일 / 데스크톱” 두 장만 그릴 거면 **375와 1440**보다 **390과 768+** 가 실제 코드에 가깝습니다. 핵심 점프가 640과 768입니다.

## 홈 세로 리듬 (섹션 간격)

홈은 “문단 사이 숨 고르기”가 큰 편입니다.  dens한 피드가 아닙니다.

| 간격 | 모바일 | 데스크톱 (640+) |
|------|--------|-----------------|
| 제목 ↔ 서브 | 22px | 22px |
| 검색 아래 ↔ 카피 | 48px | 65px |
| 카피 ↔ 슬라이드 / 슬라이드 ↔ 오늘의 앨범 / 오늘의 앨범 ↔ 차트 | 72px | 101px |
| 섹션 제목 ↔ 그 내용 | 45px | 45px |

숫자를 대충 80px로 통일하지 마세요. **72 → 101** 이 홈의 숨입니다.

## 로고 · 검색 · 히어로

| 요소 | 모바일 | 데스크톱 |
|------|--------|----------|
| 로고 | 104 × 53.8 | 141 × 72.9 |
| 검색바 높이 | 39px | 57px |
| 검색바 최대 너비 | 667px | 667px |
| 검색 버튼 | 46 × 29 | 117 × 41 |

히어로 검색은 스크롤 시 반투명 흰색 + 블러로 붙습니다 (`hero-sticky-scrolled`). 모바일은 노치(safe-area)를 패딩에 포함합니다.

## 카드 라운드

| 요소 | radius |
|------|--------|
| 피처드 카드 / 커버 | 15px |
| 슬라이드 큰 카드 | 24px |
| 리뷰 평점 뱃지 한쪽 | 오른쪽 위 10px (`rounded-tr`) |
| 인터랙션 필 | 모바일 23px / 데스크톱 거의 pill (175px) |

“전부 12px 라운드”로 리셋하지 마세요. 커버는 15, 큰 슬라이드는 24가 이미 손끝에 익은 곡선입니다.

## 피처드 슬라이드 (마퀴)

- 카드 224 × 326
- 무한 가로 스크롤, 한 바퀴 72초, 호버 시 멈춤
- 카드 사이 마진 12px

정지 캐러셀(화살표 한 장씩)로 바꾸면 홈 성격이 달라집니다. 의도적으로 **흘러가는 진열장**입니다.

## 오늘의 앨범 카드

탭이 카드 윗변에 붙고, 고른 탭 아래 선은 흰색입니다. 카드는 `-1px` 올려 탭과 이어집니다.

| 토큰 | 모바일 | 데스크톱 |
|------|--------|----------|
| 카드 | 유동 폭 × 내용 | 1098 × 529 |
| 카드 패딩 | 20 / 24 | 32 |
| 카드 테두리 | `#e4e4e7` 1px | 같음 |
| 탭 | 130 × 45, 갭 4px | 같음 |
| 커버 | 유동, 라운드 15px | 449.58², 라운드 15px |
| 커버 ↔ 텍스트 | 20px, 세로 스택 | 40px, 가로 가운데 |

Previous 탭은 **날짜별 커버 그리드**입니다. 최신 날짜가 왼쪽 위, 스크롤하면 첫 큐레이션(2026.03.16)까지 이어집니다. 날짜(`YY.MM.DD`)는 커버 **위 가운데**에 올립니다.

| 토큰 | 모바일 | 데스크톱 |
|------|--------|----------|
| 그리드 | 4열, 가운데 | 7열, 왼쪽 35px |
| 칸 | 열 너비 정사각, 라운드 10px | **120×120**, 라운드 10px |
| 칸 갭 | 12px | 28px |
| 날짜 | 14px / 29px, `#FEFEFE` | 24px / 29px, `#FEFEFE` |
| 스크롤 트랙 | 숨김 | 높이 420px, 위 54.5px, 7열 커버와 30px |

스크롤바는 네이티브를 숨기고, 데스크톱만 두께 6px / 트랙 `#d9d9d9` / 썸 `#505050` 커스텀입니다. Figma의 17px 청록 스크롤은 `display: none` 이라 제품에는 넣지 않습니다.

## 차트 탭 그림자

비활성 트랙은 **안쪽 그림자**(오목), 활성 탭은 **얕은 바깥 그림자**(볼록).  
플랫 보더만 있는 탭으로 바꾸면 “눌린 스위치” 느낌이 사라집니다.
