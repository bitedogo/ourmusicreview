# 02. 컬러 시스템

> 색은 “예쁜 팔레트”가 아니라 **역할**입니다.  
> 청록은 길 안내, 회색은 글, 빨강·주황·노랑은 **평점 전용 온도계**입니다.

아래 칩을 클릭하면 HEX가 복사됩니다.

---

## 역할별 한눈에

```
  배경 흰색 ────────────────────────────────────────
    본문 회색 (#505050)
      보조 회색 (#949494)
        흐린 회색 (#C4C4C4)  ← 플레이스홀더, /10
    포인트 청록 (#43A7B2)     ← 링크, CTA, Rating 라벨
    평점 온도계               ← 숫자 점수에만
```

---

## 브랜드 · 텍스트

| 역할 | HEX | CSS 변수 | 쓰는 곳 |
|------|-----|----------|---------|
| 브랜드 | `#43A7B2` | `--color-brand-primary` | 버튼, 링크, 활성 탭 |
| 브랜드 hover | `#3796A0` | `--color-brand-primary-hover` | 마우스 올렸을 때 한 단계 어둡게 |
| 히어로 제목 | `#35909A` | `--color-hero-title` | 홈 큰 문장 (브랜드보다 조금 진함) |
| 히어로 서브 | `rgba(67,167,178,0.55)` | `--color-hero-subtitle` | 홈 보조 문장 |
| 본문 | `#505050` | `--color-text-primary` | 거의 모든 글 |
| 보조 | `#949494` | `--color-text-secondary` | 설명, 푸터 브랜드 |
| 흐림 | `#C4C4C4` | `--color-text-muted` | `/10`, 비활성, 푸터 링크 |
| 테두리 | `#e4e4e7` | `--color-border` | 카드, 입력, 구분선 |
| 배경 | `#FFFFFF` | `--background` | 페이지 전체 |

`--color-accent` 는 브랜드와 **같은 청록**입니다. 두 번째 포인트 색이 아닙니다.

---

## 평점 색 — 제품의 서명

점수는 0.0 ~ 10.0 입니다. 색은 **구간**으로 바뀝니다.

| 구간 | 색 | HEX | 느낌 |
|------|----|-----|------|
| 9.0 이상 | 빨강 | `#F82512` | 강렬한 추천 |
| 6.0 ~ 8.9 | 주황 | `#FFA310` | 좋음 |
| 3.0 ~ 5.9 | 노랑 | `#F8CA12` | 보통 |
| 0.0 ~ 2.9 / 없음 | 청록 | `#63C4CC` | 낮음, 또는 아직 없음 |

**Why 브랜드 청록과 평점 청록이 다른가?**  
브랜드 `#43A7B2`는 “ORU 길 안내”, 평점 낮은 구간 `#63C4CC`는 “아직 차갑다”입니다.  
같은 청록 계열이지만 점수를 브랜드 버튼과 같은 색으로 칠하지 마세요.

`10.0` 만 화면에 `10` 으로 보이고, 나머지는 `8.0` 처럼 소수 한 자리를 유지합니다.

평점 색을 쓰지 말아야 할 곳: 에러 메시지, 알림 뱃지, 장터 “급처” 라벨.  
에러는 평점 빨강과 겹치면 “이 앨범이 9점인가, 실패인가”가 헷갈립니다.

---

## 오늘의 앨범

탭을 고르면 **활성 탭만 흰색**이 됩니다. 고르지 않은 탭은 날짜별 종이색을 유지합니다.

| 역할 | 색 | CSS 변수 |
|------|----|----------|
| Today 탭 (비활성) | `#FBFBFB` | `--color-today-album-tab-today` |
| Yesterday 탭 (비활성) | `#F4F4F4` | `--color-today-album-tab-yesterday` |
| Previous 탭 (비활성) | `#E3E3E3` | `--color-today-album-tab-previous` |
| 활성 탭 · 카드 | `#FFFFFF` | `bg-white` |
| 활성 탭 라벨 | `#505050` | `--color-text-primary` |
| 비활성 탭 라벨 | `#949494` | `--color-text-secondary` |
| 앨범 제목 | `#505050` | `--color-text-primary` |
| 소개글 | `#C4C4C4` | `--color-text-muted` |
| 아티스트 · 빈 소개 | `#949494` | `--color-text-secondary` |

고른 탭은 `border-b-white`와 카드 `-mt-px`로 본문과 한 장처럼 붙습니다.

---

## 푸터

푸터 글은 본문보다 한 단계 물러납니다. `#949494` / `#C4C4C4`, 크기 11px(모바일) → 16px(데스크톱).

---

## Figma → 코드로 넘길 때

개발자는 HEX를 하드코딩하기보다 **CSS 변수 이름**을 받길 원합니다.

```
Figma: Primary / #43A7B2
코드:  text-[var(--color-brand-primary)]
```

새 색이 정말 필요하면 먼저 “기존 토큰으로 안 되는지”를 보고, 필요할 때만 `globals.css`의 `:root`에 변수를 추가합니다. 화면마다 `#41A8B3`처럼 비슷한 청록을 새로 만들지 마세요.
